# M'Caravane

A single-page Vite + React site for a Kelibia tour operator. All of the styling
lives in one stylesheet, [src/styles.css](src/styles.css); the markup and the
copy in all three languages live in [src/App.jsx](src/App.jsx) and
[src/i18n.jsx](src/i18n.jsx).

## Git workflow

Every change is committed and pushed. After finishing a piece of work - a fix, a
layout change, a copy edit - run the build, then commit and push to `origin`
before reporting back:

```
npx vite build && git add -A && git commit -m "<message>" && git push
```

Do not leave finished work sitting in the working tree, and do not batch several
unrelated changes into one commit: one commit per change, pushed as it lands, so
the deployed site and `main` never drift apart.

Commit messages are a single imperative line describing the effect on the site
("Run the mobile hero photo the full height of the hero"), not the mechanism.

## Layout notes

- `dist/` is generated by `npx vite build` and is not tracked.
- The hero photo panel is cut with an SVG `clipPath` in `objectBoundingBox`
  units (`#hero-organic-clip` in App.jsx), so the same path restates itself
  against whatever box it clips. Changing the panel's proportions changes the
  curve, which is why the mobile and desktop panels are kept close in shape.
